## 🏛️ Features

✨ **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices

📱 **Mobile Optimized** - Hamburger menu for seamless mobile navigation

🎨 **Beautiful UI** - Golden and maroon color scheme matching temple aesthetics

🔍 **SEO Friendly** - Optimized for search engines

📍 **Location Map** - Embedded Google Maps for easy directions

🖼️ **Photo Gallery** - Display temple images and events

📞 **Contact Information** - Easy to find phone, email, and visiting hours

🎯 **Smooth Navigation** - Smooth scrolling between sections

🌐 **Telugu & English** - Bilingual support for better accessibility

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server-side setup required - works on GitHub Pages!

### Installation

1. Clone the repository:
```bash
git clone https://github.com/shekhartesting10-netizen/sri-jagadguru-swamy-temple.git
cd sri-jagadguru-swamy-temple
```

2. Open `index.html` in your browser

---

## 🌐 Deploying to GitHub Pages

To make this website live on the internet:

1. Go to your repository settings
2. Scroll to "GitHub Pages" section
3. Select "main" branch as the source
4. Your site will be available at: `https://shekhartesting10-netizen.github.io/sri-jagadguru-swamy-temple/`

## 📝 Customization Guide

### Change Temple Information

**In `index.html`:**

- Replace temple name in navbar
- Update contact number: Line 186
- Update email: Line 194
- Update visiting hours: Line 200

### Update Images

Replace placeholder image URLs:
- Logo: Change `https://via.placeholder.com/60`
- Gallery images: Change `https://via.placeholder.com/300x250`
- Deity images: Replace in hero section

### Change Colors

Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #8B3A1F;      /* Change to your color */
    --secondary-color: #FFD700;    /* Change to your color */
    --bg-color: #FFF8DC;           /* Change to your color */
}
```

### Update Text Content

All text is editable directly in `index.html`. Search for Telugu text to replace with your content.
